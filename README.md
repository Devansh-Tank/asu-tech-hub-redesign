# ASU Tech Hub — Page Redesign Prototype

A clickable HTML prototype for restructuring [lx.asu.edu/tech-hub](https://lx.asu.edu/tech-hub).

## What this is

A standalone, single-file prototype demonstrating a redesign of three sections of the ASU Tech Hub page:

- **What We Offer** — four pillar cards with audience filter (Student / Faculty / Staff)
- **Creative Tools & Resources** — tabbed taxonomy mirroring lx.asu.edu/technology
- **Locations & Hours** — interactive map + live "open now" status + comparison table

## How to view

Open `index.html` in any modern browser. No build step, no dependencies (Font Awesome loads from CDN).

## Design system compliance

Built within the ASU Unity Design System (UDS):
- Arial only, 16px body minimum, left-aligned, no italics, 700px text container max
- ASU Maroon (#8C1D40) and Gold (#FFC627) lead the palette
- 7-step UDS grayscale
- WCAG AA contrast on every pairing
- Font Awesome Free icons only
- Standard ASU global header and three-tier footer

## Deploy to Vercel

This repo is a static site. To deploy on Vercel:

1. Go to [vercel.com/new](https://vercel.com/new)
2. Import this repo
3. Click Deploy — that's it

Vercel will give you a URL like `your-project.vercel.app` in about 30 seconds.
